## About
Next-generation **Firebase Hub** IDE solution delivering AI-powered completions, refactoring, and code navigation.

It's aimed at everyday users as much as power users.

---

## Getting Started
1. Click the download link above to get the current version.
2. Extract all files to your preferred directory on disk.
3. Open the application launcher and complete the initial configuration.

---

## 🔧 What it does
1. **Remote Development:** SSH, container, and WSL support for coding on remote machines.
2. **Code Navigation:** Go-to-definition, find references, and symbol search across the project.
3. **Snippet Manager:** Custom code snippet library with variable placeholders and tab stops.
